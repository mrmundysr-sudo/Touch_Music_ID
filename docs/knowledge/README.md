# Project knowledge base (external memory)

CLAUDE.md requires reading this before authorised coding. It did not exist in this repo before the first build, so this is a
minimal structure. It is documentation, not automatic learning: nothing here is fabricated, and each claim links to evidence.

| File | Purpose |
|---|---|
| `PATTERNS.md` | Verified reusable patterns (each with evidence) |
| `LESSONS_LEARNED.md` | Verified lessons, including tooling/CI/sandbox pitfalls |
| `ISSUES.md` | Known issues register |
| `TESTING.md` | What has and has not been tested, and how |
| `WORK_REPORT_TEMPLATE.md` | Template for per-assignment reports |
| `reports/` | Dated work reports |

Read order for a new assignment: `reports/` (latest) → `ISSUES.md` → `TESTING.md` → `PATTERNS.md` → `LESSONS_LEARNED.md`.
